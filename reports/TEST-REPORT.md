# LukePanel v2.0.0 测试报告

生成时间：2026-08-02

## 交付物性质

这是完整仓库源码，不是升级脚本或差异补丁。仓库根目录直接包含 Go 后端、root Agent、完整 Web 前端、安装/卸载脚本、systemd 打包文件、GitHub Actions、浏览器回归测试和双架构 Linux 二进制。

前端保留现有完整功能运行时，并重构为分层设计令牌、组件级布局与统一响应式规则；本交付物不是 Vue/Quasar 源码，不对此作虚假声明。

## 功能修复

- Web 与 Agent 防火墙请求统一为 `operation + rule/number` 协议。
- UFW 参数顺序修正为 `action direction`，例如 `ufw allow in ...`。
- 添加和删除规则成功后直接采用响应中的最新 UFW 状态并重新渲染。
- 后端错误保留实际执行命令和 UFW 标准输出/错误输出。
- 增加规则动作、方向、协议、端口范围、IP/CIDR、备注及 `limit` 仅 TCP 校验。
- 防火墙表单与规则列表在手机、平板和桌面均使用独立卡片布局。
- 源码前端与 Go 内嵌前端资源保持完全同步。

## 测试边界

没有在测试容器中真正启用、关闭或改写宿主机 UFW，因为这会改变执行环境的网络策略并可能造成失联。UFW 命令生成由 Go 单元测试实际编译执行，Web/Agent 协议和真实错误输出链路由服务端契约测试及 Chromium 交互测试覆盖。最终仍建议在一台可回滚的 Debian 12/13 或 Ubuntu LTS 测试机上执行一次安装验收，再用于公网生产主机。
