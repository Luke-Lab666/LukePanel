# Roadmap

## v0.1 基础骨架

- [x] 单二进制服务
- [x] 响应式应用框架
- [x] 登录、会话、CSRF、登录限速
- [x] 系统概览
- [x] 受限文件浏览
- [x] JSONL 基础审计

## v0.2 日常管理核心

- [x] 系统概览自动刷新
- [x] 实时网络速率
- [x] root Agent 与 Unix Socket
- [x] systemd 服务管理和日志
- [x] 进程管理
- [x] 网络与存储信息
- [x] systemd timer 与 APT 更新检查
- [x] Docker 容器启停、重启、删除和日志
- [x] 镜像、网络、存储卷基础管理
- [x] 文件上传、下载、编辑、备份和回收站
- [x] Ping、DNS、TCP、HTTP 工具
- [x] 操作审计与会话管理
- [x] 高风险操作二次验证

## v0.3 扩展管理

- [ ] Docker Compose 项目
- [ ] 镜像构建、网络创建、存储卷创建和高级清理
- [ ] 容器资源实时统计
- [ ] SSH 公钥和安全配置管理
- [ ] Cron 和 timer 创建、修改、删除
- [ ] APT 升级、回滚提示与重启检测
- [ ] 文件差异对比和版本恢复界面
- [ ] 回收站恢复和跨文件系统复制

## v0.4 安全与审计

- [ ] TOTP 与恢复码
- [ ] Passkey / WebAuthn
- [ ] IP 白名单与临时封禁页面
- [ ] SQLite 审计检索、过滤和导出
- [ ] 安全告警和通知

## 不在近期范围

- Kubernetes / Swarm
- 多服务器控制中心
- 应用商店
- 网站托管和数据库面板
- 邮件服务器
- 任意 WebShell
