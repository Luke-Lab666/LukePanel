# Roadmap

## v0.1 基础骨架

- [x] 单二进制服务
- [x] 响应式应用框架
- [x] 登录、会话、CSRF、登录限速
- [x] 系统概览和基础审计

## v0.2 日常管理核心

- [x] root Agent 与 Unix Socket
- [x] systemd、进程、网络、存储、timer、更新检查
- [x] Docker 容器、镜像、网络、存储卷基础管理
- [x] 文件上传、下载、编辑、备份和回收站
- [x] 常用网络工具、日志和二次验证

## v0.3 移动端可用性与扩展管理

- [x] SSE 实时概览和后台停采
- [x] 服务搜索、运行状态筛选和移动端遮挡修复
- [x] 存储虚拟挂载过滤、路径截断和复制
- [x] 文件面包屑、复制路径、复制、移动、权限、恢复
- [x] Docker Compose 项目管理
- [x] SSH 公钥管理
- [x] 审计搜索、复制和导出
- [x] GitHub 新手发布助手和 Actions 失败重试
- [x] GitHub Release 手动运行与幂等附件上传

## v0.4 下一阶段

- [ ] 容器实时资源统计和按需终端
- [ ] Docker 高级清理、镜像构建、网络/卷创建
- [ ] 安全的计划任务创建与模板化命令
- [ ] APT 升级前检查、执行进度和可恢复策略
- [ ] 文件差异对比、备份版本列表和单文件恢复
- [ ] TOTP、恢复码、Passkey / WebAuthn
- [ ] IP 白名单、登录告警和通知
- [ ] SQLite 审计检索、轮转和导出策略

## 明确不做

- Kubernetes / Swarm
- 多服务器控制中心
- 应用商店和网站托管套件
- 邮件服务器
- 浏览器任意 WebShell
