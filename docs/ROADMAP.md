# Roadmap

## v0.1 基础骨架

- [x] 单二进制服务
- [x] 响应式应用框架
- [x] 登录、会话、CSRF、登录限速
- [x] 系统概览和基础审计

## v0.2 日常管理核心

- [x] root Agent 与 Unix Socket
- [x] systemd、进程、网络、存储、timer、更新检查
- [x] Docker 容器、镜像、网络、存储卷基础管理
- [x] 文件上传、下载、编辑、备份和回收站
- [x] 常用网络工具、日志和二次验证

## v0.3 移动端可用性与扩展管理

- [x] SSE 实时概览和后台停采
- [x] 服务搜索、运行状态筛选和移动端遮挡修复
- [x] 存储虚拟挂载过滤、路径截断和复制
- [x] 文件面包屑、复制路径、复制、移动、权限、恢复
- [x] Docker Compose 项目管理
- [x] SSH 公钥管理
- [x] 审计搜索、复制和导出
- [x] GitHub 新手发布助手和 Actions 失败重试
- [x] GitHub Release 手动运行与幂等附件上传

## v0.4 Docker 编辑、目录导入与 GitHub 推送

- [x] 概览 Docker 自动低频同步和 Swap 含义修正
- [x] 网络 AF_NETLINK 修复与 sysfs 降级
- [x] 非 Compose 容器结构化编辑、安全重建和失败回滚
- [x] Compose 配置文件编辑引导
- [x] 文件夹上传与 ZIP 安全解压
- [x] GitHub OAuth Device Flow 网页登录
- [x] GitHub ZIP 差异预览、Commit 和非强制 Push
- [x] 移动端顶部安全区和按钮换行修复

## v0.5 导航、会话与生命周期

- [x] 全局返回按钮与明确父级路由
- [x] 刷新和重新登录后恢复当前页面
- [x] 密码输入英文键盘提示与自定义二次验证弹窗
- [x] 移动端退出入口
- [x] 保留数据卸载与彻底卸载命令

## v0.6 日用闭环与安全体验

- [x] 容器实时资源统计
- [x] 按需诊断终端（仅固定命令，不做任意 WebShell）
- [x] Docker 高级清理预览、网络/卷创建
- [x] Docker 镜像构建
- [x] 安全的计划任务创建与模板化命令
- [x] APT 升级前检查、执行进度和可恢复策略
- [x] 文件差异对比、备份版本列表和单文件恢复
- [x] GitHub 分支创建、PR 创建和简单冲突提示
- [x] TOTP 与一次性恢复码
- [x] Passkey / WebAuthn
- [x] IP 白名单、登录告警和通知
- [x] SQLite 审计检索、轮转和导出策略

## v0.7 账户、SSH 与主机安全

- [x] TOTP 输入按账号状态和密码验证结果动态出现
- [x] Docker 快捷安装与全可视化容器编辑
- [x] GitHub 助手可选安装、无默认仓库和改进网页登录
- [x] SSH 密码登录安全开关、ED25519 密钥生成与下载
- [x] 用户名修改、重复密码校验和弱密码拒绝
- [x] 主机安全体检、Fail2ban 与自动安全更新
- [x] 固定模板系统诊断
- [x] 移动端标题、操作区、日志和表单视觉重构
- [x] 手动 APT 升级前下载、快照提示与可恢复流程
- [x] Docker 镜像可视化构建
- [x] Passkey / WebAuthn
- [x] 登录通知、可信设备和可恢复 IP 白名单
- [x] SQLite 审计索引与长期检索

## 明确不做

- Kubernetes / Swarm
- 多服务器控制中心
- 应用商店和网站托管套件
- 邮件服务器
- 浏览器任意 WebShell
